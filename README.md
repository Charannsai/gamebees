## New rental cart + promo features

The current project includes:
- A browser-persisted rental cart for combining multiple listings.
- Multi-item checkout using one rental date range and one order ID.
- Promo/discount code entry during checkout.
- Admin promo-code management (create, edit, delete, active/inactive status is controlled by the coupon record).
- Refined cart/product/listing UI components.

### Required Supabase migration

Before using promo codes, run `supabase/001_coupons_and_cart_orders.sql` in the Supabase SQL Editor. This creates the `coupons` table and adds grouped-order/discount fields to `bookings`.
